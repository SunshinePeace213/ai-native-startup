specs/wiki-layer · issue #88 · feat · complex

The knowledge stopped evaporating.

Every plan used to re-read the same mirrors and rebuild the same understanding, then throw it away at ship. ai-docs/wiki/ is now a tracked synthesis layer above those mirrors — schema-governed, cross-linked, and maintained by four /wiki:* operations. The personal domain never leaves this machine, and AGENTS.md now starts every task at the wiki index.

What shipped

Seven surfaces, all additive — no mirror, no sources.yaml semantic, and no harness-layer command was touched.

Tracked storage
ai-docs/wiki/ reaches the remote through a .gitignore negation; ai-docs/wiki/personal/ is re-ignored, so private pages structurally cannot be pushed.
Four operations
.claude/commands/wiki/{ingest,query,lint,status}.md — ingest opus/high, query sonnet/high, lint opus/high, status haiku/medium. Only ingest and lint write.
The layer's schema
.claude/rules/wiki-layer/wiki-standards.md, path-scoped to ai-docs/wiki/**: seven-field page schema with three status values, citation rules, writing standards, six domains, privacy, Obsidian, and the layer requirements.
Wiki-first routing
AGENTS.md now names the wiki index before the mirror index and routes gate-passing synthesis into the wiki via /wiki:ingest — inside a net +6 lines.
The seed
ai-docs/wiki/index.md (five shared domain tables plus a pointer-only Personal section) and ai-docs/wiki/log.md (the ingest and lint entry contracts).
Vault config
ai-docs/.obsidian/app.json and appearance.json — attachments at wiki/assets, links always updated; volatile workspace* state stays ignored.
Drift guard
tests/harness-layer/test_wiki_layer.py — three tests re-deriving the command set, frontmatter contracts, and rule structure from AGENTS.md, model-selection.md, and the rule itself, never from the directory under test.

    What we did not know at the start

    Three calls the build had to make that the plan could not have made for it.

    defect · found by pilot run 2

    A clean wiki could not be linted twice

    .markdownlint.jsonc sets MD024 siblings_only: true, so appending a lint log heading identical to an earlier pass — the deterministic case for a clean wiki linted twice in one day — made the auto-format hook reject the write. Run 2 had to land a truthful but distinct summary to get past it.

    Resolved A file-local <!-- markdownlint-disable MD024 --> in the seed ai-docs/wiki/log.md, since append-only logs legitimately repeat sibling headings, plus a wording fix in lint.md putting the payload "on the next non-blank line" — which the formatter's blank line had already made true. Run 3 then appended a heading byte-identical to run 2's with markdownlint at 0 errors.

    deviation · seed shape

    The index footer needed its own heading

    The spec put a bare footer line after ## Personal. The AC2 parser scopes all content following the last ## heading to that section, so a bare footer would have broken the "Personal holds only the pointer line" condition it was written to prove.

    Resolved The footer lives under its own ## Notes heading. The spec's footer requirement is still met, no locked decision was touched, and AC2 passes on the real file rather than on a relaxed check.

    judgment · standards distillation

    One ported tone rule had to go

    The source tone standard being distilled into wiki-standards.md banned em dashes outright. This repo's own prose uses them throughout, so importing the ban would have set the wiki against every other file a session reads.

    Resolved The em-dash ban was dropped; every other tone constraint carried over — flat factual voice, one claim per sentence, no peacock words, quote discipline. decisions.md locks "customize, do not port", so the call sits inside the plan's bounds.

    Also absorbed without a decision change: lint redacts a secret or PII leak in place before reporting it, rather than leaving it in a tracked file; the drift test uses the repo's house-style frontmatter parser after the spawn prompt wrongly claimed pyyaml was available under uv run pytest; two stale spec sentences (R2-F7, R2-F8) were recorded rather than acted on; and one checkpoint commit subject over 72 characters was rewritten at impl lint. One advisory stays open for review — ac5-memory-amendments.py computes its ≤14-line budget from a hardcoded list length instead of the real diff, which independently satisfies it at +9/−3.
