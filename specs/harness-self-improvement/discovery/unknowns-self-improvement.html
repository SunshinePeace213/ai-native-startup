The mental model

A self-improving harness is a closed control loop, not a pile of prompts

"Agents train agents" has a precise meaning in the field: every failure becomes a machine-checked constraint at the earliest stage that could have caught it. Prose memory is the weakest encoding; a hook or test is the strongest. Your pipeline currently runs stages 1–2 well and stages 3–5 barely at all.

1Instrument

Emit measurable traces: review rounds, finding classes, deviations. You have the files; nothing counts them.

2Detect

Classify failures against a stable taxonomy. You classify at routing time (spec / approach / detail) but persist nothing.

3Diagnose

Root-cause: was it the spec, the builder, the reviewer — or the harness itself? The fourth answer is never recorded.

4Encode

Fix at the cheapest stage: template > checklist > lint > hook. A dev-log line is a queue entry, not a fix.

5Verify

Regression evals so the harness never silently loses what it learned. Today only hooks have tests.

The aviation model: every item on a pre-flight checklist is a past crash. A recurring Codex finding class that hasn't become a plan-time check yet is a crash you're scheduled to have again.

Domain gap · quality bar

How professionals judge whether a harness is actually improving

Not by feel. By these, each derivable from files the pipeline already commits:

  • Rounds-to-approval trends down across consecutive plans (soriza-cpo: 9 spec rounds; kb-seed: 5 + 2 — today nobody computes the trend).
  • No finding class ever recurs twice — a second occurrence means stage 4 (Encode) failed, not that the builder was careless.
  • The harness eval suite is green on every harness commit — a prompt-file edit that drops a load-bearing section fails CI, instead of surfacing two plans later.
  • The pipeline's own machinery produces zero dev-log deviations — every "tool wasn't available / push refused / hook stranded the run" entry is a harness bug, and counts as one.
  • A fresh agent can run the pipeline from the docs alone — tribal knowledge in your head is friction the layer hasn't absorbed yet.
